# Datasets Strategy — Smart Parking Occupancy Analytics
**Course:** AI372IA — Stream Processing and Analytics  
**Institution:** RV College of Engineering, Bengaluru  

---

## 1. Primary Data Source: Synthetic Virtual Sensor Network
All real-time streaming data demonstrated in this system is continuously generated by the Python-based virtual IoT sensor network simulator located in `simulator/`.

- **Source Tag:** Every event is tagged with `"source": "SIMULATED_SENSOR"`.
- **Purpose:** Guaranteed, deterministic, offline-capable continuous streaming source supporting configurable workloads (10, 50, 100, 500, 1,000+ events/sec).
- **Academic Focus:** Demonstrates streaming transformations, event-time watermarking, and stateful occupancy calculation independently of external network reliability.

### Academic Disclaimer on Bengaluru Data:
1. The OpenCity.in open dataset does not publish continuous live telemetry for smart slots.
2. Slot capacities (e.g., 120, 80, 200) are **configured academic assumptions** chosen to reflect realistic commercial surface and multi-level lots.
3. Coordinates are preserved for GIS mapping, zone rollups, and dashboard visualization.

## 3. Historical Sensor Replay Dataset: City of Melbourne 2019
The project supports historical event replay using real IoT sensor datasets from the City of Melbourne open data portal (`https://data.melbourne.vic.gov.au/`).

- **Dataset:** 2019 On-Street Parking Bay Sensors.
- **Coverage:** On-street parking bay arrivals and departures.
- **Replay Utility:** Implemented in `ingestion/historical_replay.py`.
- **Attribution & License:** Creative Commons Attribution 4.0 International (CC BY 4.0).
- **Source Label:** Replayed events are explicitly stamped with `"source": "HISTORICAL_REPLAY"` and `"city": "Melbourne"`.
- **Academic Integrity Rule:** Historical Melbourne data is never mixed or falsely presented as Bengaluru real-time data.
